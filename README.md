### Backend
* **Платформа:** .NET 8 Web API
* **База данных:** MySQL (Managed Service on Aiven Cloud)
* **ORM:** Entity Framework Core
* **Аутентификация:** JWT (JSON Web Tokens) & ASP.NET Core Identity
* **Документация API:** Swagger / OpenAPI
